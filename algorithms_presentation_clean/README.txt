# Алгоритмы и исполнители — веб-презентация

Откройте `index.html` в браузере.

Управление:
- → / Пробел / PageDown — следующий слайд
- ← / PageUp — предыдущий
- Home / End — первый / последний слайд
- F — полный экран
- Можно кликать по правой или левой части экрана
- На телефоне работают свайпы

Файлы:
- index.html — структура презентации
- style.css — оформление и анимации
- script.js — навигация и интерактив
